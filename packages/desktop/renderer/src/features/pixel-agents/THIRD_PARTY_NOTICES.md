# Pixel Agents Integration Notice

ROOM's `PixelAgentStage` is an internal React component designed to connect ROOM discussion and task-run events to a pixel-office style presentation.

The integration is intentionally host-native: ROOM does not embed the upstream VS Code extension runtime, Claude transcript watcher, or webview application.
