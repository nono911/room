# ROOM Domain Glossary

## AI Workspace

- **Template**: A built-in persona blueprint such as UX, Developer, Product, or Reviewer. A template is not directly executed once it has been instantiated.
- **Member**: A saved AI agent configuration in a workspace. A member has its own name, role, provider, model, prompt, skills, and execution settings.
- **Team**: An ordered group of saved members. A team references members; it does not copy member configuration.
- **Persona Variant**: A generated specialization of a template, used when creating multiple members from the same template so they bring different perspectives.
- **Unassigned**: A virtual team containing saved members that are not referenced by any user-created team.
- **Temporary Member**: A one-run participant added to a discussion or task without saving a member file.
